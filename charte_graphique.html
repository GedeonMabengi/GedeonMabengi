1. Presentation du Logo

Le logo GMK_Dev est compose d'une fenetre d'editeur de code (IDE) aux coins arrondis, contenant les initiales GMK en majuscules avec le suffixe _dev en orange. Le symbole </> dans la barre de titre rappelle l'univers du developpement web.

Concept : Le logo evoque un terminal de developpeur — l'environnement naturel du codeur. Les initiales GMK occupent l'espace central, affirmant l'identite, tandis que le _dev en bas a gauche signale la specialite.

4. Regles d'Utilisation

4.1 Espace de Protection

Le logo doit toujours etre entoure d'un espace vide minimum egal a la hauteur du _dev sur tous les cotes. Cet espace de protection garantit la lisibilite et l'integrite du logo.

Regle d'or : Ne jamais placer de texte, d'image ou d'element graphique dans la zone de protection du logo.

4.2 Taille Minimale

Version Taille minimale
Principale 120 px de large minimum
Favicon 32 x 32 px
Impression 30 mm de large minimum

4.3 Utilisations Correctes et Incorrectes

Sur fond fonce

Utiliser la version inversee (blanche) ou la version principale sur fond noir.

Sur fond clair

Utiliser la version principale (transparente).

Interdictions

NE JAMAIS
  • Deformer le logo (etirer, compresser)
  • Changer les couleurs du logo
  • Ajouter des effets (ombres, degrades, contours)
  • Tourner le logo
  • Separer les elements du logo
  • Utiliser le logo sur un fond de couleur vive
  • Placer le logo trop petit (< 120px)
TOUJOURS
  • Respecter les proportions du logo
  • Utiliser les couleurs de la charte
  • Preserver l'espace de protection
  • Utiliser la version adaptee au fond
  • Maintenir le logo a une taille lisible
  • Preferer les fonds neutres (blanc, noir, gris)

6. Signature Visuelle

Elements identitaires

L'identite visuelle GMK_Dev repose sur quatre elements distinctifs :

Element Signification
La fenetre code arrondie Symbole universel du developpement, l'IDE est l'atelier du codeur
Le </> orange Identite developpeur, symbole HTML universel du web
Le _dev Suffixe signature en orange, rappelle la specialite technique
Les lettres GMK Initiales en gris clair, bien visibles, ancrent l'identite personnelle

Ambiance

L'univers visuel GMK_Dev est defini par :

  • Brutalisme doux — formes geometriques pures, pas d'ornement superflu
  • Minimalisme technique — chaque element a une fonction
  • Monochrome + accent — noir, blanc, gris avec un seul point d'orange
  • Style editorial — typographie bold, espaces blancs genereux
  • Images en noir et blanc — coherence photographique totale
Philosophie : "Chaque pixel, chaque interaction, chaque ligne de code est intentionnel. Pas de remplissage. Pas de bruit. Juste du craft brut."
