# CHARTE GRAPHIQUE - GMK_Dev

## 1. PRESENTATION DU LOGO

Le logo GMK_Dev est compose d'une fenetre d'editeur de code (IDE) arrondie contenant les initiales "GMK" en majuscules avec le suffixe "_dev" en orange. Le symbole </> dans la barre de titre rappelle l'univers du developpement web.

### Versions du logo

| Version | Usage | Fichier |
|---------|-------|---------|
| **Principale (transparent)** | Usage general, fonds clairs ou dores | `logo_gmk_main.png` |
| **Horizontale** | Bannieres, en-tetes larges | `logo_gmk_horizontal.png` |
| **Monochrome** | Impression noir/blanc, gravure | `logo_gmk_monochrome.png` |
| **Inversee (blanche)** | Fonds sombres, footer noir | `logo_gmk_inverted.png` |
| **Favicon** | Onglet navigateur, icone app | `logo_gmk_favicon.png` |

## 4. REGLES D'UTILISATION

### Espace de protection

Le logo doit toujours etre entoure d'un espace vide minimum egal a la hauteur du `_dev` sur tous les cotes.

### Taille minimale

- **Version principale** : 120px de large minimum
- **Favicon** : 32x32px

### Sur fond fonce
Utiliser la version **inversee** (blanche) ou la version principale sur fond noir.

### Sur fond clair
Utiliser la version **principale** (transparente).

### Ce qu'il ne faut PAS faire

- Ne pas deformer le logo (etirer, compresser)
- Ne pas changer les couleurs du logo
- Ne pas ajouter des effets (ombres, degrades, contours)
- Ne pas tourner le logo
- Ne pas separer les elements du logo
- Ne pas utiliser le logo sur un fond de couleur vive

## 5. SIGNATURE VISUELLE

### Elements identitaires

1. **La fenetre code arrondie** - Symbole du developpement
2. **Le </> orange** - Identite developpeur
3. **Le _dev** - Signature orange en bas a gauche
4. **Les lettres GMK** - Initiales en gris clair bien visibles

### Ambiance

Brutaliste, minimaliste, monochrome avec un seul accent orange. Style editorial et technique. Espaces blancs genereux. Images en noir et blanc uniquement.
